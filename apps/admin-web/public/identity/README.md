# Recursos de identidad del acceso

- `reduniv-logo.png`: copia sin modificaciones del logo entregado por el propietario en `diseño/reduniv_logo.png`.
- `google-g.png`: icono oficial obtenido de https://developers.google.com/static/identity/images/g-logo.png. Se conserva su proporción y color.
- `google-sans-latin.woff2`: subconjunto latino de Google Sans Medium obtenido desde Google Fonts. La licencia SIL OFL se incluye en `google-sans-LICENSE.txt`.

El botón de Google sigue las indicaciones de https://developers.google.com/identity/branding-guidelines. Los recursos se sirven localmente; el navegador no contacta con Google para descargar imágenes o fuentes al mostrar esta pantalla.
