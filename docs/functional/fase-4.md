# Fase 4: colaboradores, logística y operaciones económicas

## Paquete 1: patrocinadores y colaboradores — implementado

Catálogo por evento con instituciones, contactos privados, logotipos y enlaces; categorías bilingües; aportes económicos/en especie/servicios, responsables, fechas, estados y evidencia; seguimiento y sumas por moneda; selección autorizada, vista previa, publicación independiente y retirada motivada; historial/versiones inmutables. Comprobaciones dirigidas de API y navegador, con datos sintéticos separados. Ver [guía](../development/patrocinadores-colaboradores.md) y [ADR-030](../adr/ADR-030-patrocinadores-colaboradores.md).

## Paquetes posteriores — pendientes

Logística sobre el catálogo de salas existente: recursos, equipamiento, solicitudes y necesidades por actividad/sesión. Reservas/aforo y participación híbrida requieren reglas específicas.

Cobros y conciliación: pendientes de definir modelo institucional, monedas, medios de cobro, comprobantes y responsabilidades. Registrar compromisos de patrocinio no implementa estos procesos.

La activación de identidad/correo y la validación integral conservan sus pendientes independientes. Este incremento no declara la plataforma lista para producción.
